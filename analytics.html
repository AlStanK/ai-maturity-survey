Аналітика зрілості (Metabase BI)

Анкета Metabase (localhost:3030)
База: Neon (survey) · Схема: public
Психологічна безпека
v_company_summary

Шкала Едмондсон (ps1–ps7): безпека експериментування та визнання помилок при роботі з ШІ.

Лідерство та правила
gv1 – gv8

Наявність політик безпеки, чітких регламентів, стимулів та підтримки керівництва.

Розрив узгодженості
v_perception_gap

Різниця оцінки стану між лідерами (C-level) та командами (поріг ≥ 2 керівників, ≥ 3 виконавців).

Розриви по процесах
v_process_gaps

Різниця між поточним використанням («зараз») та очікуваною потребою («потрібно»).

Дашборд Metabase очікує підключення

Для відображення зведеної аналітики запустіть локальний Metabase та вставте посилання на публічний дашборд у поле вище.

1
Запустіть контейнер Metabase:
cd deploy && docker compose -f docker-compose.metabase.yml up -d
2
Підключіть базу Neon:
Відкрийте http://localhost:3030, оберіть PostgreSQL, базу survey.
3
Отримайте посилання вбудовування:
У дашборді натисніть Sharing & Embedding → Public link та скопіюйте посилання.
